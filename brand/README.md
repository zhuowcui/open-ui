# Div brand assets

The Div logo is the lowercase wordmark `div/`, set in Geist with the slash in
Div blue. The icon is `d/` on a dark rounded square. Open
[`preview.html`](preview.html) to see every asset at real sizes.

Every file here is generated by [`build.py`](build.py). Don't edit the SVGs or
PNGs by hand: change the parameters at the top of the script and rebuild.

## Files

| File | Use |
| --- | --- |
| `logo/div-wordmark.svg` | Full color on light backgrounds |
| `logo/div-wordmark-dark.svg` | Full color on dark backgrounds |
| `logo/div-wordmark-black.svg` | One color, black (print, embossing, single-ink) |
| `logo/div-wordmark-white.svg` | One color, white (photos, the accent color, dark single-ink) |
| `logo/*.png` | The same four, 192 px high, transparent, for places that can't take SVG |
| `icon/favicon.svg` | Browser favicon (fitted to a 16 px grid; crisp at 16, 32 and 48) |
| `icon/favicon.ico` | 16, 32 and 48 px, each fitted to its own pixel grid |
| `icon/favicon-16/32/48.png` | The images inside the `.ico` |
| `icon/apple-touch-icon.png` | 180 px, full bleed; iOS rounds the corners |
| `icon/div-icon.svg`, `icon/icon-64/192/512.png` | The master icon: tile with transparent corners (PWA `any`) |
| `icon/icon-maskable.svg`, `icon/icon-maskable-192/512.png` | PWA `maskable`: full bleed, mark inside the 80% safe zone |
| `icon/app-icon.svg`, `icon/app-icon-512/1024.png` | Desktop app icon on the macOS grid, with shadow |
| `og/og-image.png` (`.svg` source) | 1200 × 630 Open Graph and social card |

For a website `<head>`:

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta property="og:image" content="https://div.build/og-image.png">
```

and in `site.webmanifest`:

```json
"icons": [
  { "src": "/icon-192.png", "type": "image/png", "sizes": "192x192" },
  { "src": "/icon-512.png", "type": "image/png", "sizes": "512x512" },
  { "src": "/icon-maskable-512.png", "type": "image/png", "sizes": "512x512", "purpose": "maskable" }
]
```

## Colors

| Name | Value | Use | Contrast |
| --- | --- | --- | --- |
| Div blue | `#266EFB`, `oklch(0.58 0.223 262)` | The slash | 4.46:1 on white and on Ink |
| Ink | `#09090B` (zinc-950) | Letters on light; the icon tile | 19.9:1 on white |
| Paper | `#FAFAFA` (zinc-50) | Letters on dark | 19.1:1 on Ink |

The slash is a graphic, so it needs 3:1 against its background (WCAG 1.4.11).
Div blue has the same contrast on white and on Ink, the most any single color
can have against both, so the full-color logo uses one blue on light and dark.
Use the one-color versions on any background where the blue falls below 3:1.

## Clear space and minimum size

- Keep at least one x-height (the height of the v) clear on every side of the
  wordmark, and a quarter of the tile's width around the icon.
- The wordmark's minimum size is 16 px high on screen, or 5 mm in print. Below
  that, use the icon.
- The icon's minimum size is 16 px. Below 64 px, use the grid-fitted favicon
  files rather than scaling the master down.

## Don'ts

- Don't retype the wordmark in Geist or any other font; use the files. The
  spacing and the slash are drawn, not typed.
- Don't change the slash's color to anything but Div blue, or the one color
  of a one-color version.
- Don't stretch, slant, outline, add effects to, or rotate the logo.
- Don't rearrange it: no capital D, no `/div`, no `<div>`, and no slash on
  its own as a logo.
- Don't put the full-color logo on busy images or on mid-tone backgrounds
  where the slash drops below 3:1; use a one-color version.
- Don't recolor the icon tile; it stays Ink.

## Construction

- **Letters**: Geist's d, i and v, from the variable font instanced at weight
  550 (between Medium and SemiBold), converted to outlines. Spacing is
  tightened by 40 units after the d and 26 after the i (1000 units per em).
- **Slash**: drawn, not Geist's glyph. It runs from the baseline to the top
  of the d, parallel to the v's right arm (20.1° from vertical), with
  horizontal cuts. Its horizontal thickness is 96% of the stem, which reads as
  equal weight over its longer length. It sits 130 units from the v at the
  baseline, so the two parallel edges form an even channel.
- **Icon**: Geist's d with the same slash, 34 units from the stem at the
  baseline. The mark is 60% of the tile's width, placed halfway between the
  box centre and its visual centre of mass, then raised 1.2%. The tile is a
  rounded square (radius 22.4% of the side) with 60% corner smoothing, so the
  curvature ramps up from the straight edges instead of jumping.
- **Small sizes**: at 16, 32 and 48 px the d's key edges (bowl, counter,
  stem, baseline, x-height, ascender) are moved onto whole pixels and the rest
  of the outline is interpolated between them, like a TrueType hinter. At 16
  px the mark is larger (75% of the tile), the stem and bowl are 2 px, and the
  slash is slightly steeper so a full pixel separates it from the d.

## Rebuilding

From the repository root, with Python 3.10 or later:

```bash
python -m pip install -r brand/requirements.txt
```

```bash
python -I brand/build.py
```

The script writes every file listed above, plus `preview.html` from
`preview.template.html`. Output is deterministic: rebuilding with the pinned
versions gives byte-identical files.
