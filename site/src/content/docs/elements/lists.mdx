`<li>` is a block with `display: list-item`, which gives it a marker, a
disc, outside its box. `<ul>` and `<ol>` are plain [block
elements](/elements/div/) that hold the items.

## Markers

The marker is set with the `list-style` property, which takes `disc` (the
default) or `none`. There are no numbered markers: `<ol>` does not count
its items, and `decimal` is not a value Div accepts. Write the numbers
as text, as in the example, or put them in their own `<span>`.

An outside marker sits to the left of the item, so a list with no padding
draws its markers outside its own box. Give the list a `padding-left`, as
in the example. `list-style-position` (`outside` or `inside`) is a typed
style, set with `Element::set_list_style_position`.

The marker itself can be styled through the `::marker` pseudo-element:
`Element::set_pseudo_style(PseudoStyleTarget::Marker, &style)`.

## Attributes and events

None of their own. `value` on `<li>` and `start` or `reversed` on `<ol>`
have no effect. Events are those of any block; see
[div](/elements/div/#events).

## Rendering a list from data

Use `For`, which keeps one item per key and adds, removes and reorders
items as the data changes. It returns a view that you mount into the list
element; see [Events and state](/docs/concepts/events-and-state/)
for a complete example.

## Accessibility

All three are `GenericContainer`; there is no list or list-item role by
default. Set `AccessibilityRole::List` and `ListItem` with
`set_accessibility_role` when a screen reader should announce a list.

## Differences from HTML

| HTML | Div |
| --- | --- |
| `ul` and `ol` have padding and margins | None: add `padding-left` for the markers |
| `ol` numbers its items (`decimal`, `lower-alpha`…) | Only `disc` and `none`: write numbers as text |
| List and list-item roles | `GenericContainer` |
| `dl`, `dt`, `dd`, `menu` | Not supported |
