`<br />` ends the current line, as in HTML. `<wbr />` marks a place where
the line may break if the text does not fit, which helps long words such as
paths and URLs wrap at sensible points. Both take no children; write them
self-closing.

## Attributes, events and styling

Neither reads an attribute or receives events of its own. They have no box
to style: `<br />` takes the `line-height` of the text it breaks.

Outside text, use layout instead of `<br />`: stack blocks, or use `gap` in
a flex column. Inside text, CSS also wraps long words with
`overflow-wrap: anywhere` or `word-break`, without markup.

## Accessibility

`<br>` has the `LineBreak` role. `<wbr>` is `GenericContainer` and is not
announced.

## Differences from HTML

None in behavior.
