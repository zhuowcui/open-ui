`<ruby>` pairs base text with a small annotation, `<rt>`, drawn above it:
the reading of East Asian characters, for example. Div lays the base
and its annotation out as one unit, so they never split across lines.

<ElementTable tags={['ruby', 'rt']} links={false} />

## Writing ruby

Put the base text first and its `<rt>` after it, inside one `<ruby>`. Use
one `<ruby>` per base, as in the example. `<rp>` and `<rb>` are not
supported tags.

<Aside type="caution" title="Leave room for the annotation">
The annotation is drawn above the line without making the line taller. Give
the text a `line-height` large enough for it (the example uses `2`), or the
annotation overlaps the line above.
</Aside>

## Styling

`<rt>` takes text styles; a smaller `font-size` is usual, since it has none
by default. Ruby layout has three typed styles: `set_ruby_position`,
`set_ruby_align` and `set_ruby_overhang`.

## Attributes, events and accessibility

No attributes of their own; events as for [span](/elements/span/).
The roles are `Ruby` and `RubyAnnotation`.

## Differences from HTML

| HTML | Div |
| --- | --- |
| `rt` is half size by default | No default size |
| The line grows to fit annotations | Leave room with `line-height` |
| `rp`, `rb`, `rtc` | Not supported |
