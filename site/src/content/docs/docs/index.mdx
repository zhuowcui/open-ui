Open UI is a framework for building native desktop apps in Rust. You
describe the interface with a `view!` macro that reads like HTML, style it
with CSS properties, and ship one native binary. Open UI lays out and
paints your views itself, with Skia.

**Open UI is not a browser.** There is no HTML document, no JavaScript and
no webview. The tags in `view!` are Open UI's own native elements, which
borrow HTML's names; the set is closed, they have no default styles, and
some behave differently from their HTML namesakes. Knowing the elements is
the first step, so they have [their own reference](/open-ui/elements/).

<Aside type="caution" title="Alpha">
Open UI is an experimental alpha for Windows and Linux. The first alpha
release is still in progress, APIs change without notice, and nothing is
on crates.io yet. macOS is planned.
</Aside>

## What an app looks like

<Snippet name="app_minimal" title="src/main.rs" />

- **Elements.** `div`, `button`, `input` and the other
  [base elements](/open-ui/elements/) are what every view is made of.
- **Views** are Rust functions that return `view!` markup. Components are
  functions marked `#[component]`.
- **Styles** are CSS properties and values, set on each element and
  checked when the app compiles.
- **State** lives in signals. When a signal changes, the text and styles
  that read it update.
- **App services**: windows, menus, file dialogs, clipboard, HTTP and async
  tasks are part of the framework.

app builds it locally.
