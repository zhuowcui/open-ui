Open UI ships [shadcn/ui](https://ui.shadcn.com/)'s components rebuilt in
Rust, with the same variants, sizes and colors, in light and dark. Each one
is checked against shadcn/ui rendered in Chrome. The images on this page are
rendered by Open UI.

The crate is `openui-components`, in the repository's
[`components/`](https://github.com/zhuowcui/open-ui/tree/main/components)
folder. It is not published yet.

## Button

<div class="ou-shot"><Shot name="buttons" alt="Buttons in the default, secondary, outline, ghost, destructive and link styles" /></div>

```rust
use openui_components::*;

view! {
    <Button variant={ButtonVariant::Outline} size={ButtonSize::Sm} disabled={false}>
        "Export"
    </Button>
}
```

Variants: `Default`, `Secondary`, `Outline`, `Ghost`, `Destructive`, `Link`.
Sizes: `Xs`, `Sm`, `Default`, `Lg`.

## Card

`Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardAction`,
`CardContent` and `CardFooter` are available. Their layout is still taller
than shadcn/ui's, because of a column flexbox difference that is being fixed
(see [Rendering](/open-ui/docs/rendering/)), so the panels in these
screenshots are built from styled elements instead.
