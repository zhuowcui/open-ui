# Project website v0, 10 November 2026

A static website for the project, in `site/`, built with Astro 7.3.8 and
Starlight 0.42.8 and deployed to GitHub Pages
(`https://zhuowcui.github.io/open-ui/`) by `.github/workflows/site.yml`.
Plan workstream E (brand and web presence) and D (docs infrastructure). It
changes no engine, framework or components source.

## What shipped

| Change | Source |
| --- | --- |
| Home page: hero, alpha notice, the Chromium and Open UI comparison slider with a diff overlay and a zoom to real pixels, current numbers with citations, a `view!` example taken from the default template, three principles, the merged app services, platform status, and notes that the site is HTML and that the project is unrelated to the W3C Open UI Community Group | `site/src/pages/index.astro`, `site/src/components/CompareSlider.astro` |
| Getting started, from `openui-cli` and its `default` template on `main` | `site/src/content/docs/getting-started.md` |
| Fidelity: the pinned oracle, the suites, the no-regression gate, current numbers and known failures, each with its record | `site/src/content/docs/fidelity.md` |
| Stubs: docs, components, roadmap, devlog, about | `site/src/content/docs/` |
| Theme: zinc neutrals, self-hosted Geist and Geist Mono, green for exact and magenta for a mismatch, light and dark | `site/src/styles/` |
| Asset sync with hash checks and its own pixel count | `site/scripts/sync-assets.mjs`, `site/scripts/assets.json` |
| Build on pull requests and deploy from `main`, path-filtered to `site/**` and the workflow; actions pinned by commit | `.github/workflows/site.yml` |

slider uses the committed fragmented fieldset evidence: 1600×900 captures

147.0.7727.50, per `baseline__receipt.json.gz`. The page fills the top-left
750×540 pixels, which the site shows with CSS; the files are not cropped.

The deploy job checks that Pages is enabled and skips with a notice if not.
Enabling it (Settings, Pages, Source: GitHub Actions) is a repository setting
for the owner to change.
